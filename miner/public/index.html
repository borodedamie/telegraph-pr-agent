Package Release Intel

Telegraph miner 7314: what changed in an npm package between two versions.

Ask about one npm package and two versions. You get the breaking changes, deprecations and security fixes for every release in that range. Each item quotes the release notes word for word and links to its source. Known advisories are checked against OSV. Releases that could not be read are named in the answer, not guessed.

Calling it

This page is not the API: questions go through Telegraph and are paid with x402 (0.02 USDC per answer, testnet). Ask miner 7314 by id; auto-routing sends these questions elsewhere.

POST https://devnode.telegraphprotocol.com/engine/v1/ask/7314
{"method":"GET","endpoint":"/answer","payload":{"query":"What changed in zod from 3.23.8 to 4.0.0?"}}

Asking well

  • One npm package per question, both versions, oldest first: What changed in express from 4.21.0 to 5.0.0?
  • npm only, at most 2,000 characters.
  • A first answer takes a few seconds, up to about 20 s for a large jump. A repeat comes from the cache in under a second.
